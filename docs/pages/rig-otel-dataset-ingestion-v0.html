This dataset captures OpenTelemetry traces, logs, and metrics into a local analytical substrate so Rig Relay can study tool and agent behavior before deciding which hardening slices matter.

Local-only by default

OpenTelemetry is observed locally, normalized locally, and analyzed locally. It does not become authoritative coordination truth, release-gate truth, or a remote vendor feed.

  • OpenCode spans and events
  • OpenTelemetry Collector file exports
  • future local emitters that already speak OTLP

Redaction posture

Raw prompts, raw completions, credentials, secrets, private file contents, private repo contents, and raw absolute paths are hashed or dropped before normalization and summary generation.

The normalized dataset is read-side only. It informs future tool hardening and may later emit seam-level coordination events, but it does not directly mutate the Coordination Event Ledger in this slice.

Useful signals from this dataset can later map into coordination seam events such as repeated tool failures, retry loops, missing parent spans, or high-latency tool categories.

  • No remote telemetry exporter
  • No canonical coordination ledger writes
  • No release-gate mutation path
  • No DuckDB mutation authority
  • No dependency additions beyond existing repo dependencies
