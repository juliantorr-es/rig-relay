Storage Retention Policy

This policy is active for local Rig Relay storage. Review required before enabling remote telemetry or cloud sync.

Scope

  • Session interaction logs (.rig/relay/sessions/)
  • Artifact storage (.build/rig-relay/)
  • Telemetry events (observability.jsonl)
  • Trace events (trace_events.jsonl)
  • Coordination store (.build/rig-relay/coordination/)
  • Desktop cockpit state (chat_state.json, chat_events.jsonl)

Garbage Collection

Passive GC runs after tool execution when the storage budget is exceeded. Active GC can be triggered via scripts/rig_relay_gc_artifacts.py. The GC policy prunes stale leases, expired artifacts, and old session data. Evidence and receipts are preserved unless they exceed the retention window.

Privacy

All storage is local-first by default. No data leaves the machine without explicit opt-in. Telemetry and trace exports are opt-in only. Artifact GC never transmits data externally. The packaged app stores data under ~/Library/Application Support/Rig Relay/.

Storage Budget

compute_storage_summary() checks total artifact size against a configurable budget. Status values: ok (under budget), warn (approaching limit), over_budget (GC triggered), fleet_blocked (no new sessions until GC completes).
