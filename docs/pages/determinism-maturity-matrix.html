Executive Summary

Rig Relay is currently at **Level 1 (Partially Controlled)** for most core components. While it has a deterministic serialization foundation (`dump_canonical_json`), it suffers from "Ambient Environment Dependency" (global home paths, unsorted filesystem traversal, random IDs).

Detailed Findings

DET-001: Global Home Bias

Location: `vibe/core/paths/_vibe_home.py` Risk: All evidence from all projects ends up in one folder, making per-run validation and cleanup difficult. Recommendation: Implement local-first resolution (Git root discovery).

Recommended Backlog

1. **Mission: Monotonic Sequence Enforcer**: Add sequence numbers to all JSONL events. 2. **Mission: Content-Addressed Evidence**: Use hashes for session and artifact IDs. 3. **Mission: Canonical Traversal**: Enforce `sorted()` on all directory walks/glob results.
