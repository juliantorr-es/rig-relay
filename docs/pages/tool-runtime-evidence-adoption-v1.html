Privacy Model

The following fields are **never** emitted into ToolRuntime trace spans, result dicts, or receipt envelope: - Raw stdout, stderr, argv, cwd, env, shell command - Frontend paths, URLs - Auth tokens, API keys - Raw exception repr strings (truncated to 500 chars for error_message)

Allowed in trace/receipt: envelope id, envelope sha, classification, byte counts, hashes, safe refusal/error kind, duration, tool name, tool call id.
