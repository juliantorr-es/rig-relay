Shared Degradation Rules (6 rules — must survive refactor)

  • Mutation gate failures → BLOCK, REVIEW, or DEGRADED, never ALLOW
  • Read-only tools may continue when only governance availability is the problem
  • Missing evidence must surface as unknown, not none
  • Dev bypass only when explicitly enabled and labeled
  • Policy hints remain advisory until a policy object is injected
  • Coordination failure → dry-run or refusal, not unleashed write

Non-Negotiable Runtime Invariants (Must Survive All Waves)

  • Missing governance capability must degrade to a typed refusal or review state, never to ALLOW.
  • Missing context evidence must be reported as unknown, not as a fabricated safe path.
  • Tool execution must accept an explicit policy object; permissive defaults are not acceptable for mutation paths.
  • Trace identifiers must survive refusal, degrade, and success paths unchanged enough to correlate logs, receipts, and tool results.
  • The shell should not know how to make policy decisions; it should only route requests and consume runtime results.
  • Read-only behavior may continue under degraded governance, but mutation must not proceed without explicit authority.
  • AgentLoop must not import rig_relay.desktop.*, rig_relay.ralph.*, rig_relay.analytics.*, duckdb.
  • After extraction, no method in orchestrator shell should spend >50% of its code using attributes from a single domain.

What the Unified Compiler Enables

The previously created unified compiler package (rig_relay/compiler/) provides shared infrastructure that the refactored AgentLoop shell can use: GateMatrix for validation gate enforcement, CompilerEvidence for structured evidence emission, CompilerWorktree for git worktree isolation, and the 3 newly implemented context modes (HANDOFF for cross-agent coordination, COLLISION for path conflict detection, SYMBOLS for token compression). These reduce the amount of custom code needed in the shell.

Compiler capabilityHow the shell uses it
HANDOFF mode (compile_handoff_packet)SessionRuntime.fork() produces a handoff packet before spawning subagent. Replaces ad-hoc state copying.
COLLISION mode (compile_collision_report)ContextRuntime checks for path conflicts before tool execution. Replaces do-not-touch list assembly in compiler.py.
SYMBOLS mode (compile_symbol_packet)ContextRuntime injects symbol substitutions into context packets. POPULATES the previously-dead symbol_map field.
GateMatrix + STANDARD_GATE_MATRIX (10 gates)ToolExecutor, GovernanceRuntime, and SessionRuntime can each run validation gates using shared infrastructure.
CompilerEvidenceAll runtime modules produce content-light structured evidence using the shared evidence emitter.
CompilerWorktreeSessionRuntime.fork() creates isolated worktrees for subagent missions using shared worktree management.
