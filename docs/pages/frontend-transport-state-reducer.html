Model Summary

Use the shared transport reducer as the only source of connection truth. Update status rendering whenever transport state changes.

Required Invariants

  • wsConnected is derived from the transport reducer, not local shadow state.
  • Status bar rerenders on transport transitions.
  • Browser breadcrumbs track rendered state.
  • Status contradiction detection exists.
  • No legacy local state can override reducer truth.

Forbidden Patterns

  • local wsConnected shadowing shared state
  • connected without renderStatusBar
  • direct status chip mutation outside reducer path
