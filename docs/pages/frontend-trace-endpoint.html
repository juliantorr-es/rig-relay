Model Summary

Use the browser-safe frontend trace sink. Emit breadcrumbs through /frontend-event with type and handshake_id. Never route frontend breadcrumbs to /ws or emit token values.

Required Invariants

  • Frontend trace events use field type, not event.
  • Browser fallback sends only to /frontend-event.
  • Trace endpoint never derives from ws_url or websocket_url.
  • No POST /ws.
  • No token values are emitted in URL, body, console, trace, or debug panel.
  • WebSocket /ws remains WebSocket-only.

Forbidden Patterns

  • POST to /ws
  • token in query string
  • trace sink derived from websocket_url
