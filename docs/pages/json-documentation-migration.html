Model Summary

Treat documentation migrations as JSON-first changes. Keep the migration manifest, site manifest, and renderer in sync and do not author new Markdown for migrated content.

Required Invariants

  • No new Markdown docs are created for migrated content.
  • Migration manifest maps old_path to new_path.
  • Rendered docs must come from site_manifest entries.
  • render_static_docs.py must run after docs/json or docs/schemas changes.
  • Progressive disclosure metadata is required for new docs.

Forbidden Patterns

  • new Markdown docs
  • generated docs as source context
  • HTML source docs
