Model Summary

Use the desktop golden path as the proof artifact. Trace startup, websocket connect, auth, projection, and status rendering with canonical handshake_id.

Required Invariants

  • Startup logs report host, port, frontend_url, websocket_url, tls_enabled, token_present, and transport_label.
  • Auth success must emit canonical handshake_id.
  • Projection sent, received, and rendered must be traced.
  • Status rendered must follow connection success.
  • Playwright browser integration is release evidence.
  • Simulated trace tests are analyzer tests, not launch proof.
  • No untrusted TLS is labeled secure.

Forbidden Patterns

  • Secure Local Bridge
  • missing handshake_id
  • ws_url without /ws
