Deliberate Gaps

- Protected execution buttons remain absent - Bash, write, search, upload, spawn, fleet, and delegate controls remain locked - Full provider network checks are not implemented - Full local model downloads are not part of alpha - Production OAuth code exchange is not part of this slice - Telemetry upload remains opt-in and off by default - Local model benchmarking is a scaffold, not a released capability

Product Constraints

- Textual remains a legacy fallback - Demo and release copy stay alpha-labeled - High-authority actions still require backend validation and receipts - The frontend remains a renderer, not a governor

- No raw prompts - No raw model outputs - No source code - No diffs - No stdout/stderr bodies - No tokens or secrets - No raw private paths in shareable artifacts
