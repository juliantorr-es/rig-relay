Model Summary

Use the tool-batch lifecycle as a governed runtime seam. Preserve single-use execution, trace evidence, and result envelopes.

Required Invariants

  • Tool batches are single-use.
  • Trace and receipt evidence must be emitted for execution.
  • Pending batch lifecycle is explicit.
  • tool_batch_id is required.
  • execute_tool_batch with no pending batch is a structured no-op or refusal.
  • Failure or cancellation cannot leave stale executable pending state.
  • Trace events are content-light and contain no raw args or secrets.

Forbidden Patterns

  • silent batch reuse
  • multiple executions of the same batch
  • batch without trace evidence
