Use a local OpenTelemetry Collector or OTLP JSON export only. Bind receivers to localhost, export to local files, and keep remote exporters disabled by default.

  • OTLP HTTP endpoint: http://localhost:4318
  • OTLP gRPC endpoint: localhost:4317
  • OTEL_EXPORTER_OTLP_ENDPOINT=http://localhost:4318
  • OTEL_EXPORTER_OTLP_PROTOCOL=http/protobuf
  • OTEL_SERVICE_NAME=opencode-rig-relay-dev
  • OTEL_RESOURCE_ATTRIBUTES=project=rig-relay,environment=local-dev,telemetry_source=opencode
  • memory_limiter or an equivalent local safeguard
  • batch
  • attributes redaction or hashing for risky keys before file export

Write raw capture files to .build/rig-relay/otel/raw/<run_id>/otel_raw.json and keep exporter output local. Remote exporters stay prohibited unless a later slice explicitly changes the policy.

Do not enable remote export by default

Remote vendors are not part of this slice. The collector description is local-first and read-side only.
