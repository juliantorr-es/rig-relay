Tracing Doctrine

Rig Relay tracing is structured runtime evidence using spans, events, and redacted attributes. It is not random logging. Tracing answers: what operation happened, where, which parent caused it, how long it took, whether it passed or failed.

Event Kinds

  • span.start — emitted when a span begins
  • span.end — emitted when a span ends (includes duration, status)
  • span.event — emitted inside a span (child event)
  • span.error — emitted on error outside a span

Redaction Rules

Before writing to JSONL, every trace event is sanitized. The following are redacted: token, auth_token, api_key, password, secret, authorization, cookie, bearer. Allowed safe fields: token_present (boolean), token_length (integer). Strings over 1000 chars are truncated. Nested dicts/lists are recursively sanitized.

Usage

from rig_relay.tracing import TraceRecorder, get_default_trace_store

store = get_default_trace_store()
recorder = TraceRecorder(store)

with recorder.span("desktop.bridge.start", {"host": "127.0.0.1"}) as span:
    span.event("port_bound", {"port": 9876})
    # ... work ...
# span.end emitted automatically with ok/error status

RuntimeSupervisor Span Contract

RuntimeSupervisor emits a dedicated runtime.subprocess.execute span for each supervised subprocess. The span records safe metadata only: executable, argv_hash, argv_count, cwd_hash, timeout seconds, lease ID, lane/workspace identifier, shell usage flag. Child events record subprocess lifecycle milestones: spawn.start, spawn.ok, stdout.chunk, stderr.chunk, timeout, kill, exit, result_classified. Raw stdout/stderr content, raw argv, and environment values are never emitted.

Runtime Supervisor Result Envelope

Canonical terminal evidence for supervised subprocess execution is carried by RuntimeSupervisorResultEnvelope. The envelope uses the same terminal classification vocabulary as the runtime.subprocess.execute span summary. Downstream consumers should read the envelope rather than reconstructing subprocess state from raw process handles. ToolRuntime and adapter receipts preserve the envelope fields for subprocess-backed tool calls so trace summaries, receipts, and audit events stay aligned.

OpenTelemetry Compatibility

Dotted operation names follow OpenTelemetry semantic conventions. Future exporter can translate Rig JSONL traces to OTel format. No remote exporter in v0 — local-first only.
