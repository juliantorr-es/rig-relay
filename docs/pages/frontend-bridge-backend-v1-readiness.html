CPU Budget Philosophy

CPU budget is measured in counts, not wall-clock. Bounds are enforced by queue caps (_MAX_PER_CONNECTION_QUEUE = 64), coalesce semantics (COALESCE_KINDS = {lifecycle_event, heartbeat}), never-drop protection (NEVER_DROP_KINDS = {error, intent_result}), and drop counting (record_dropped). ProtocolTracker.snapshot() reports only count-based metrics: coalesced_count, dropped_count, max_queue_depth, no wall-clock or elapsed-time fields. Tests validate message count and byte throughput per operation, coalesce count per drain cycle, and drop enforcement at cap boundaries.
