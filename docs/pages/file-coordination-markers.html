File Coordination Markers

Agents claim files before edits, release them after edits, and scan markers before touching shared work. JSON and generated outputs use the sidecar ledger only.

States

  • active: file is currently owned by a session.
  • released_modified: file changed and may accept additive follow-up work.
  • released_readonly: file was inspected or tagged but not modified.

Safety boundary

Inline markers are only inserted where comments are safe. The sidecar ledger records every claim and release event append-only.
