Pi Harness Extension Health

Extension crashes are isolated at the extension boundary. The harness records crash metadata, keeps session finalization available, and quarantines repeat offenders.

Rules

  • Wrap activation and event handling in per-extension try/except boundaries.
  • Record extension id, phase, redacted message, traceback hash, timestamp, session id, and crash count.
  • Quarantine repeat offenders after the policy threshold.
  • Use safe mode to start with nonessential extensions disabled.
  • Expose a health status command and a quarantine-clear command.

Operational meaning

A quarantined extension stays disabled on future startup until cleared intentionally. Failures remain visible in structured health state instead of being hidden.
