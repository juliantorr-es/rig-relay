# Beta Telemetry Onboarding

Rig Relay is a governed coding-agent harness, not a normal chat assistant.
Its advanced features depend on structured operational telemetry that is
separated into three distinct layers:

1. **Local operational telemetry** — required for governed mode
2. **Local derived datasets** — required for reporting and orchestration
3. **Remote beta data sharing** — optional, content-light, used during the
   private beta to improve Rig Relay across participants.

## What Rig Relay Is

Rig Relay is a local agent harness that coordinates bounded child sessions
in a structured, governed way. It is designed to protect dirty files, prevent
path conflicts, and create checkpoint evidence — not to mine your data.

## What Is Never Uploaded

Regardless of your telemetry settings, Rig Relay never uploads:

- Raw source code
- Raw prompts (the full instructions sent to language models)
- Raw model outputs (the full text generated by language models)
- stdout/stderr bodies
- Diffs or patches
- Secrets, API keys, or tokens
- Raw private file contents
- Git authorship metadata or commit trailers

Rig Relay does not add silent co-author trailers like "Generated by Rig Relay"
or "Co-Authored-By: Rig Relay" to your commits. Ever.

## What Remote Beta Sharing Includes

If you enable remote beta data sharing (default-on for private beta after
onboarding disclosure), Rig Relay may upload content-light bundles that contain:

- Event names (e.g. `tool_call_completed`, `checkpoint_committed`)
- Tool names (e.g. `read_file`, `search_replace`)
- Statuses and refusal codes
- Timings and byte counts
- SHA256 hashes of files and paths (salted, not reversible)
- Row counts and dataset sizes
- Provider and model metadata (model name, version)
- Checkpoint and coordination outcomes
- Finding IDs and severity levels

## Telemetry Modes

| Mode | Local Telemetry | Remote Sharing | Advanced Features |
|------|----------------|----------------|-------------------|
| `basic_local` | Optional | Disabled | Disabled |
| `governed_local` | Required | Disabled | Enabled locally |
| `beta_orchestration` | Required | Required | Full stack |

### basic_local
- No remote sharing.
- Advanced orchestration disabled.
- Basic read, search, and single-session local use with local safety.

### governed_local
- Local operational telemetry enabled.
- Remote sharing disabled.
- Delegation, checkpointing, coordination, and queue planning work locally.
- Reserved for local-only / future enterprise mode.

### beta_orchestration
- Remote beta data sharing enabled.
- Full advanced feature stack enabled.
- Contributes content-light derived usage data to the project maintainer.

## How to Disable Remote Sharing

To disable remote beta data sharing and revert to basic local mode:

1. Set `remote_beta_sharing_enabled = false` in your telemetry settings.
2. Or set `mode = "basic_local"` to fully opt out of advanced features.

Advanced orchestration features will become unavailable, but local safety and
basic single-session use remain fully functional.

## Data Deletion and Export

If you have previously shared beta data and wish to request deletion or an
export of what was collected, contact the project maintainer. Bundle contents
are content-light derived rows only — no raw private code or prompts.
