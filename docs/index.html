Rig Relay

Governed local runtime for agent work.

AI agents can change code faster than people can inspect what happened. Rig Relay makes agent work observable, controlled, and reviewable.

Rig Relay is like a controlled workstation for AI agents. Instead of letting agents mutate code invisibly, it gives the work a station, a mirror, a checklist, and receipts.

Features

Governed Execution

Agent tools are permission-gated. Destructive operations require approval. Stale batch reuse is prevented.

Correlated Tracing

Trace events carry correlation IDs and handshake IDs. Content-light doctrine keeps secrets out of traces.

Evidence Receipts

Every agent action produces verifiable receipts. Reports are append-only JSONL. Ralph scans for regressions.

Code Schemas

Implementation contracts encoded as JSON. Authority hashes prevent tampering. Context assembler routes tasks to schemas.

Static Evidence Site

All documentation is canonical JSON rendered to static HTML. No backend, no database, no tracking.

Security-Aware Bridge

Desktop bridge validates WebSocket origins and messages. Auth-before-subscribe. Invalid message guard closes abusive connections.
