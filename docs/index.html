Rig Relay

A governed local agent platform for making AI-assisted software work inspectable, auditable, and refusal-first.

AI agents can change code faster than people can inspect what happened. Rig Relay turns agent execution, provider access, protocol calls, compiler candidates, bridge events, runtime observations, CI evidence, and coordination artifacts into schema-governed, trace-correlated, content-light, refusal-first local evidence.

Why It Matters

Most AI coding agents operate as black boxes. They mutate code, call external APIs, and produce results with no audit trail. Rig Relay rejects that model. Every tool call is permission-gated, every action produces verifiable receipts, every protocol boundary has a refusal vocabulary, and every release candidate is validated against schema-governed contracts before promotion. The evidence is not marketing — it is inspectable.

What Rig Relay Does

Governed Execution

Agent tools are permission-gated with ToolPermission (ALWAYS/ASK/NEVER). Destructive operations require explicit approval. Stale batch reuse is prevented by lease-gated supervision.

Trace-Correlated Evidence

Every agent action carries trace IDs and correlation IDs across 10 surfaces. Content-light doctrine ensures secrets never leak into traces. Cross-surface events are joinable.

Refusal-First Boundaries

A shared refusal vocabulary with 29 classes spans MCP, ACP, A2A, SDK, and provider surfaces. Capabilities are refused by default and granted explicitly.

Schema-Governed Contracts

0+ JSON schemas govern every artifact type. Implementation contracts are encoded as JSON with authority hashes. The deterministic compiler validates worktrees against contracts.

Protocol Spine

MCP (Model Context Protocol), ACP (Agent Client Protocol), A2A (Agent-to-Agent), and SDK surfaces each have capability manifests, readiness checks, and refusal adapters.

Static Evidence Site

This site is deterministically generated from canonical JSON artifacts. No backend, no database, no tracking. Every page is schema-validated and safety-scanned before publication.

Frequently Asked Questions

What is Rig Relay?
Rig Relay is a governed local agent platform. It provides a controlled runtime for AI coding agents that produces inspectable, auditable evidence of every action taken — tool calls, file mutations, protocol interactions, and model requests.
Who is it for?
Engineering teams, security-conscious organizations, and individual developers who want agent-assisted development with governance guardrails, audit trails, and bounded claims rather than opaque execution.
What makes it different?
Most coding agents optimize for speed. Rig Relay optimizes for inspectability. Every surface has a refusal vocabulary. Every artifact validates against a schema. Every claim is bounded by evidence. Known seams are documented, not hidden.
What is proven?
0+ schemas validated. Cross-surface refusal vocabulary covering 10 protocol surfaces. Deterministic site compilation. Content-light evidence receipts. Release gate validation. See the proof chain for full details.
What is deferred?
Production OAuth, full OS sandboxing, resource budget enforcement, and PNG social preview images are documented deferrals. See known seams for the complete list.
